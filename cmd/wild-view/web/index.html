配置说明

1. 本程序只读取账号额度与模型倍率，不提供任何会话转发接口：/v1/* 一律返回 404， 也不存在任何转发入口。

2. 添加账号后会自动完成登录，并在后台按周期刷新额度与模型目录。单个账号失败不影响其他账号。

3. 「全部刷新积分」立即查询所有账号的最新余额；余额变化曲线记录的是每次查询成功时的实际值， 下降可能来自消耗、到期或套餐回收，不等同于对话消耗。

4. 模型倍率按账号分别查询。同一模型在不同账号倍率不同时会逐账号标注；上游未返回倍率时显示 unknown，不代表免费。

5. 纯签到默认关闭，可在「设置 → 纯签到」中开启。开启后只执行不依赖对话的签到； 依赖对话的渠道（WorkBuddy 国际版、智谱清言）不参与签到，也不会做任何聊天保活。

6. 账号显示名可点击卡片上的名字直接修改；顶栏齿轮进入设置（监听地址 / 管理密码 / 纯签到 / 开机自启 / 临期阈值）。

7. 数据目录默认为 exe 同级的 wild-view-data/，可用环境变量 WILDVIEW_HOME 指定； 日志位于 wild-view-data/data/app.log，可从托盘菜单打开。

8. 退出程序：右键托盘图标选择「退出」。
